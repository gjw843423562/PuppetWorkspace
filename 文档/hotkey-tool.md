# 快捷键工具使用说明

从 Puppet 的“快捷工具”页面启动，也可独立运行 `发布/快捷键工具/PuppetHotkeys/PuppetHotkeys.exe`。首次显示窗口需要加载界面，Puppet 按钮会立即给出等待反馈；再次点击时唤醒已有窗口。

## 配置与操作

当前配置统一位于 `配置/快捷键工具.json`，保留已有七个工具及整行 `//` 注释。`MainHotkey` 显示主窗口，`Tools` 里的 `Hotkey` 启动对应程序、目录或网址；`Args` 是可选字符串数组。优先通过界面新增、编辑、删除并保存；外部编辑后点击“重新加载”。保存成功后立即应用，无需重启。

编辑期间暂停全局热键；录入框支持直接按组合键，路径框支持文件和目录拖入。工具间重复键会被拒绝，被其他应用占用时显示具体错误。热键重载失败会恢复原绑定。若关闭后隐藏到托盘，可用主快捷键或托盘菜单显示；托盘菜单提供退出。

自启开关只控制新版工具的当前用户项，整理迁移保留原开关状态。旧版工具不应同时运行，否则可能占用相同热键。

## 保存与排障

配置保存前检查外部修改，备份到 `运行数据/备份/快捷键工具/`，再用临时文件原子替换。日志位于 `运行数据/日志/快捷键工具/`：`hotkeys.log` 为轮转运行日志，`crash.log` 为原生崩溃信息。显式传入其他配置时，日志与备份隔离在该配置旁的 `logs`、`backups`。

启动报缺失文件时，按提示检查正式 EXE、完整 `_internal` 与配置，不复制历史归档覆盖新版本。错误配置不会被默认模板覆盖。使用 `--check` 可只验证配置，不注册热键或启动目标。

## 实现与验证边界

原程序没有源码，当前为自主实现的 Python/Tkinter 独立工具。Windows `RegisterHotKey` 接收全局热键，原生回调只将事件入队，Tk 主线程处理窗口；目标启动在线程执行，结果返回界面。命名互斥量按配置路径区分实例，重复启动唤醒现有窗口。目录式发布避免单文件版每次解包。

自动化覆盖配置保存、外部修改保护、热键回滚、队列消息、自启隔离、隔离 EXE 启动与唤醒。真实键盘、NumLock 差异、资源管理器拖放、登录后自启仍需用户桌面体验验收，不能用合成消息测试代替。历史原版分析和早期发布记录完整保留在 `历史记录/hotkey-tool.md`。
